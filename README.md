# Codex Agentic Governance

Tres skills de invocación explícita para diseñar proyectos y workflows agénticos eficientes, trazables y mantenibles.

## Skills

- `$bootstrap-agentic-project`: crea el sistema mínimo de instrucciones y contexto material.
- `$design-efficient-workflow`: diseña workflows con economía de cómputo, recuperación selectiva, estados, validaciones y límites.
- `$maintain-knowledge-ledger`: mantiene un índice canónico de decisiones, supuestos, evidencia e incertidumbres.

Las tres tienen `allow_implicit_invocation: false`: Codex solo debe cargarlas cuando se mencionen por nombre.

## Instalación

Copiar o enlazar cada carpeta dentro de `skills/` al directorio personal de skills de Codex.
