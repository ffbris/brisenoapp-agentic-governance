# Decisiones de desviación

| Resultado | Condición | Contexto |
|---|---|---|
| Continue | Aprendizaje compatible con decisión y modelo vigentes | Registrar sólo si es material |
| Extend | Cambia un supuesto, método o componente acotado | Actualizar artefactos afectados |
| Branch | Pregunta separable con evidencia o entregable propio | Crear vínculo, interfaz y condición de reintegración |
| Reframe | Cambia decisión, dueño, unidad, éxito, evidencia o lógica | Proponer migración y pedir autorización |

## Prueba de rama

Una rama debe tener pregunta, resultado, límites y condición de reintegración propios. Si no puede separarse sin redefinir el proyecto matriz, considerar reencuadre.

## Prueba de preservación

Antes de recomendar cambios, distinguir resultados:

- todavía válidos;
- válidos con reinterpretación;
- pendientes de reprocesamiento;
- invalidados sólo si existe evidencia suficiente.
