# Modelo de manejo

Clasificar según consecuencia y obligación, no sólo por tipo de dato:

- público;
- interno;
- confidencial;
- restringido o regulado.

Para cada etapa registrar:

| Etapa | Datos necesarios | Herramienta o ambiente | Acceso | Persistencia | Audiencia |
|---|---|---|---|---|---|

## Principios

- La autorización depende de finalidad, herramienta, ambiente y audiencia.
- Minimizar por etapa; el análisis puede requerir más detalle que la divulgación.
- Seudonimización no equivale a anonimización.
- Agregación puede seguir permitiendo reidentificación.
- Conclusión sensible no es necesariamente conclusión imprecisa.
- El ledger conserva conocimiento material y referencias, no bases de datos.

## Escalar

Solicitar decisión cuando falten autorización, base aplicable, clasificación, control del ambiente o definición de audiencia. No improvisar una solución jurídica.
