# Gobernanza conceptual

## Orden de autoridad predeterminado

1. Ley o norma vinculante.
2. Contrato o definición del cliente.
3. Definición aprobada para el proyecto.
4. Definición disciplinaria adoptada.
5. Definición organizacional.
6. Lenguaje general.

El orden puede modificarse expresamente. Mayor autoridad no significa alcance universal.

## Ciclo

`proponer → comparar → aprobar → registrar → propagar → verificar`

Estados recomendados:

- `draft`;
- `current`;
- `deprecated`;
- `superseded`;
- `contested`.

## Cambio material

Tratar como material si puede cambiar clasificación, medición, interpretación, obligación, causalidad, recomendación o comparabilidad histórica.

## Relaciones

Usar `broader_than`, `narrower_than`, `related_not_equivalent`, `conflicts_with` y `supersedes`. Verificar que cada destino exista.
