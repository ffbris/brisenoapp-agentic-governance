# Contratos de revisión documental

## Sustantiva

Pasar a `$whole-problem-reviewer`:

- target: `substantive`;
- problema o decisión sustantiva;
- corpus autorizado;
- afirmaciones y recomendaciones;
- decisiones cerradas;
- incertidumbres aceptadas;
- prohibición de editar o reencuadrar.

Revisar tesis, evidencia, alternativas, inferencias, implicaciones y utilidad decisional.

## Comunicativa

Pasar a `$whole-problem-reviewer`:

- target: `communication`;
- audiencia;
- decisión, comprensión o acción esperada;
- contenido aprobado provisionalmente;
- formato y restricciones;
- decisiones sustantivas cerradas;
- prohibición de iniciar nueva investigación.

Revisar fidelidad, jerarquía, contexto, interpretación, navegabilidad y capacidad de acción.

## Escalamiento

Una revisión comunicativa puede emitir `external substantive blocker` cuando el contenido autorizado impida una comunicación honesta. Debe describir el conflicto sin investigarlo ni resolverlo.

Una revisión sustantiva puede emitir `framing review indicated`. La decisión vuelve a `$frame-decision-project`; no se modifica el proyecto dentro del flujo documental.
